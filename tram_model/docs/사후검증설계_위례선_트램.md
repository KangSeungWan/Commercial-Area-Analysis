# 개통 뒤 이렇게 검증한다 — 위례선(2026-12 개통 예정)·대전 2호선(2030) 사후 검증 설계 (2026-11-03)

이 분석은 '예측'이 아니라 비슷한 과거 사례(대전 1호선·서울 신림선·해외 트램)로 만든 사전 경고다.
국내 첫 지상 트램인 위례선이 개통하면, 같은 질문을 지상 트램 자료로 직접 검증할 수 있다. 결과를 보기 전에 방법을 정해 둔다.

## 1. 질문 (이 분석의 주장과 1:1)
| # | 주장 | 위례선에서 볼 결과 |
|---|---|---|
| ① | 정거장 주변 땅값이 오르는 방향 | 개별공시지가(필지), 실거래가(상업·업무용) |
| ② | 카페 비중이 늘어남(가장 확실) | 행안부 인허가(휴게음식점 카페), 상가정보 분기 |
| ③ | 점포당 매출은 땅값만큼 오르지 않음 | 서울 상권분석 추정매출(분기), 카드사 자료 |
| ④ | 땅값-매출 간극 → 나중 임대료 | 부동산원 임대가격지수(해당 하위상권), 공실률 |
| ⑤ | 공사 기간 매출 감소 | 공사 구간 상권 월 매출(공사 전 12개월 이상 확보) |

## 2. 설계
- 처리: 정거장 500m 안 (필지·점포·상권 중심점). 거리 띠 0~150 / 150~300 / 300~500 / 500~750m 따로
- 비교: 정거장 1~3km, 같은 자치구(송파·성남·하남) 안, 개통 전 3년 상권 밀도(점포/㎢)로 짝지음
- 기간: 개통 전 최소 3년(땅값 연·점포 분기), 개통 뒤 1~4년
- 모형: 이중차분(단위 고정효과 + 기간 고정효과), 사건연구(개통 시점 −12~+16분기), 군집 표준오차(법정동 또는 상권)
- 검사(대전 분석과 같음): 사전 추세, 가짜 개통 시점(2년 앞당김), 가짜 처리군(비교군 안 무작위 200회), 반경 400·750m 변형
- 다중 검정: 위 표 5개 주장 × 핵심 결과 1개씩만 '본 검정'으로 미리 지정, 나머지는 탐색
- 판정 규칙(미리 정함): 본 검정이 p<0.05 이고 사전 추세 통과 → '지상 트램에서 확인' / 아니면 '확인 안 됨'. 대전 기본값(땅값 +1.8%)과 신뢰구간이 겹치지 않으면 기본값을 위례선 값으로 교체 검토

## 3. 대전 2호선(2030)에 바로 쓰기
- 지금 정해 둘 것: 처리·비교 단위(행정동 82·상권 20·골목상권 144), 공사 구간 표(공구별 시작 달), 기준 시점 자료 보관(8989 2026-09까지 수집본)
- 공사 기간(2025~2029): 골목상권 월 매출로 ⑤를 매년 갱신 — 공사 구간까지 거리·공사 개월 수별 효과(analyze_construction_dose.py)
- 개통 뒤(2030~): 위 설계 그대로, 결과가 이 앱의 사전 경고와 맞았는지 공개

## 4. 한계
- 위례선은 신도시(위례) 노선이라 원도심을 지나는 대전 2호선과 상권 성격이 다름 → 원도심형 정거장만 따로 보는 하위 분석 필요
- 서울 상권분석 추정매출도 카드사 추정치
