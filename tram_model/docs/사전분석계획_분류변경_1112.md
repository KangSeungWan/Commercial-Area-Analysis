## 0. 왜 바꾸나 (결과가 아니라 사용자 때문)
- 11/4 주 사용자 확정: 시·구 소상공인·상권 정책 담당자(B2G). 분류는 '상권의 미래 전망'이 아니라 **담당자가 할 일**을 알려 줘야 한다.
- 기존 분류의 문제(코드 확인)
  1. '트램 반등 기회' = 위험 ≥ 50 **그리고 점포 절반 이상이 정거장 500m 안**(`IN500_MIN` 0.5). 즉 **거리만으로** '기회'가 붙음. '확실' 등급인 업종(카페) 변화는 분류에 안 들어감. 트램 땅값 효과(등급 '방향만')는 성장 점수에만 들어가 '성장 지속/정체' 구분에 영향
  2. 위험이 큰 곳에도 '기회'라는 이름이 붙음
  3. 상권 20곳 = 8·5·4·3 안에 노선 밖 비교군 8곳이 섞여 있음
  4. 담당자 업무 ①(공사 구간 우선순위)이 분류에 없음

## 2. 두 축
### 가로축 — 지금 위험 (트램과 무관한 현재 상태)
- 위험 점수 = 기존 그대로: 점포 비중 10년·3년(↓), 폐업률(↑), 지가 대전 대비 10년·최근 4년(↓), 2034 지가 예측(트램 없음, ↓)의 백분위 평균. 상권은 20곳, 동은 82곳 안 순위(비교군 포함해 계산, 분류만 대상에게)
- **높음** = 위험 점수 ≥ **50**(기존 `rcut=50`) **그리고** 절대 쇠퇴 신호 '있음' 또는 '강함'
  - 절대 쇠퇴 신호(`absolute_decline.py`): '있음' = 점포 비중 최근 3년 감소 **그리고** 폐업률이 대전 평균(82개 동 점포 가중)보다 높음, '강함' = 4개 조건 모두
- **낮음** = 그 밖의 모두. **'판단 안 함'(점포 지표 없음: 도룡동 상권·신성동)은 '낮음'**

### 세로축 — 트램이 바꿀 정도 (업종 변화)
- 값: **`cafe_bakery_pp`(웹 `comp.base.pp`) = 2034년 기본 시나리오에서 전체 점포 중 카페·빵 비중이 지금보다 늘어나는 %p**(`build_composition.py`). 기본 시나리오는 빵 효과 0이라 사실상 **카페 비중 변화**. 카페 곳 수는 쓰지 않음
  - 계산 방식 주의: 1호선 평균 효과(+24.8%) × 그 단위 카페 중 정거장 500m 안 비율 × 개통 뒤 연차 모양. '확실' 등급은 **1호선 평균 효과**의 등급이고, 각 상권 값은 그 효과를 지금 카페 분포에 적용한 **추정**
- **변화 큼** = 대상 안 가운데값 이상, **변화 작음** = 가운데값 미만. 상권은 상권 대상끼리, 동은 동 대상끼리. 짝수면 가운데 두 값의 평균
- 땅값 효과는 축에서 빼고 상권 카드·근거 장에만 둠(성장 점수는 카드 참고값으로만 남김)

## 3. 네 칸 이름과 뜻
| 칸 | 이름 | 뜻(범례 한 줄) |
|---|---|---|
| 위험 높음 · 변화 큼 | **먼저 지원** | 지금도 어렵고 트램으로 업종이 크게 바뀔 곳 → 공사 중·개통 초 지원 우선 |
| 위험 높음 · 변화 작음 | **기존 지원 연계** | 어려움은 트램보다 원래 있던 쇠퇴 때문 → 기존 소상공인 정책과 연결 |
| 위험 낮음 · 변화 큼 | **변화 관찰** | 지금은 괜찮지만 업종이 크게 바뀔 곳 → 업종 변화 지켜보기 |
| 위험 낮음 · 변화 작음 | **정기 점검** | 변화가 적은 곳 → 분기 갱신 때 다시 보기 |
| (노선 밖) | **비교 지역** | 분류하지 않음(회색) |

## 4. 분류에 영향 주지 않는 겹침 표시
- **공사 구간** 테두리 + 공사 기간. 정보공개 2번(공구별 공사 일정)이 오면 **공사 시작 달만 교체**, 분류는 그대로
- **임대료 '지켜볼 곳' ⚑** = 임대료 신호 등급 '높음'(칸과 무관, 어느 칸에나 붙을 수 있음)
- 전통시장 진회색 테두리, 좌표 흔들림 ⚑ — 기존 그대로
- **같은 칸 안의 순서**: 공사 구간 안 → 공사 기간이 긴 곳 → 위험 점수 높은 곳

## 5. 안정도 확인 (새 축에 맞춘 변형, 기준은 기존과 같음)
- 변형 10가지: 위험 지표 하나씩 빼기(6) · 위험 선 45/55(2) · 업종 값 낮음/높음 시나리오(2)
- 같은 칸이 나온 비율 < **0.8**(기존 `STABLE_MIN`)이면 '불확실' 표시
- 정거장 좌표 300회 흔들기(`analyze_station_sensitivity.py`)는 새 분류 기준으로 다시 돌려 칸이 바뀌는 비율을 기록
- 기존 분류(`quadrant`)는 지우지 않고 `quadrant_old`로 보존, 바뀐 상권·동 목록을 근거 문서에 기록
