# 사전 분석 계획 (2026-11-03 16시 30분, 결과를 보기 전에 작성)

2차 점검(`claude/점검_3가지입장_2차_1103.md`)의 지적 "결과를 보고 해석을 바꾼다(사후 재정의)"를 반복하지 않기 위해,
재분석을 돌리기 전에 **어떤 결과가 나오면 무엇을 바꾸는지**를 먼저 적는다. 결과가 불리해도 아래 규칙대로 반영한다.

## B5 — 1호선 2단계 음수의 원인 (기본값 결정)
- 방법: 2단계 역 500m 필지에서 1996~2011년 필지가 1.5배 이상 늘어난 법정동(개발지)을 빼고 다시 이중차분.
  보조: 1996년에 이미 있던 필지만. 비교군도 같은 기준으로 자름. 효과 창 2008~2011, 사전 추세 창 2000~2003(2005=0).
- 판정 (변형 '개발지 제외' 기준)
  - R1/R2: 사전 추세가 ±3% 안 → 2단계는 '해석 가능'. **새 기본값 = 1단계 + 2단계(개발지 제외) 합산값.** 커지든 작아지든 그대로 쓴다.
  - R3: 사전 추세가 ±3% 밖 → 2단계는 '평행 추세 실패로 해석 불가'. **기본값은 바꾸지 않는다(+1.8% 유지)**, 이유를 화면·보고서에 명시.
  - 1단계 +5.8%를 기본으로 올리는 선택지는 쓰지 않는다.

## B1 — 0.24배의 불확실성
- 방법: 행정동 75개를 다시 뽑는 부트스트랩 2,000회. 매 회 땅값 계수(b_L)와 매출 계수(b_S)를 같은 표본에서 추정 →
  비율 b_S/b_L 과 차이 b_L − b_S 의 2.5~97.5% 구간.
- 판정
  - 차이 구간이 0보다 위 → "땅값 차이가 매출 차이보다 크다" 문장 유지, ③ 등급 '방향만'.
  - 차이 구간이 0 포함 → "땅값과 매출의 차이도 확인되지 않았다", ③ 등급 '확인 안 됨'.
  - 어느 쪽이든 비율 한 점(0.24배)은 핵심 표에서 빼고 구간으로 적는다.

## B2 — 임대료 간극의 타당성 (전국 상권)
- 방법: R-ONE 전국 상권에서 간극 = (자산가치 변화 − 임대료 변화)를 앞 시기에 계산, 뒤 시기 임대료 변화와 스피어만 상관.
- 판정 (단측 아님, p<0.05)
  - ρ>0 유의 → "간극이 큰 곳은 뒤에 임대료가 더 오른다" → ④를 '나중 임대료 상승 신호'로 되돌림.
  - 유의하지 않음 → ④는 '간극 현황'으로만, 예측·위험이라는 말 쓰지 않음.
  - ρ<0 유의 → 대전 6곳 결과와 같음 → ④ 처방에서 임대료 상승 대비 수단(상생협약 선제 지정)을 빼고 '모니터링'만.

## B3 — 공사 피해 (처리군 안 비교)
- 방법: 골목상권 공사 구간 상권을 공사 구간까지 거리 띠·공사 개월 수로 나눠 처리 강도별 효과.
- 판정: 가장 가까운 띠의 효과가 가장 크고(음의 방향) 95% 구간이 0을 넘지 않으며, 공사 개월이 길수록 커지면 → '공사 피해 방향 확인'.
  아니면 '동 평균 손실 확인 안 됨' 유지.

## B4 — 신림선 땅값 (서울 공시지가 받으면)
- 방법: 매출 분석과 같은 처리(역 500m)·비교(1~3km)·기간(개통 2022-05, 사전 2019~2022, 사후 2023~2024).
- 판정: 땅값 효과 유의하게 양수 & 점포당 매출 유의하지 않음 → 핵심 주장 '같은 사례에서 확인'. 땅값도 유의하지 않음 → "경전철은 땅값도 매출도 확실히 바꾸지 않았다", ①은 '방향만' 유지하고 기본값 그대로.

## B7 — 8989 동 간 편향
- 방법: 단면 회귀에 20~39세 주민 비율, 대학 유무 통제 추가.
- 판정: 매출 계수가 기본 대비 부호가 바뀌거나 절댓값이 50% 넘게 바뀌면 ③ 문구에 "구성 통제에 민감"을 추가.

## B10 — 진단의 시간 순서 검증 (11/18 재수집 뒤)
- 방법: 2025년 상반기 자료로 만든 위험 점수 → 2026년 폐업률·매출 변화 순위상관.
- 판정: ρ 방향이 맞고 p<0.05 → "진단은 다음 해 폐업과 관련", 아니면 진단을 '현황 요약'으로 표현.
