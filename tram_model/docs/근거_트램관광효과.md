# 근거: 트램 관광 효과 (해외·국내 문헌·데이터, 2026-10-25)

> 조사 범위: 해외 학술 30 · 해외 도시 사례·공식 통계 22 · 방법론·탄력성 12 · 국내 문헌 12 · 데이터셋 14 = **90건**. 전체 표와 상세는 `tram_model/data/literature_tram_tourism.csv`(90행) 와 보고서 `tram_model/docs/근거_트램관광효과_보고서.md`. 시나리오 계수는 `tram_model/data/tourism_params.csv`(14개).
> 읽은 범위 표기: 원문 / 일부 / 초록 / 2차 / 기사 / 목차. **'하' 등급(기사·위키·운영사 주장)은 효과 크기로 쓰지 않음.**

## 0. 한 줄 결론
세계 어디에도 **"트램 개통 → 관광객·숙박·호텔 가동률이 늘었다"를 인과적으로 측정한 연구는 없다.** 입증된 것은 "관광객이 트램을 탄다"(이용 비중)까지다. 따라서 결과물 이름은 '관광 효과 추정'이 아니라 **'관광 접근성 변화와 외지인 소비 시나리오'**(문헌 계수 범위를 빌린 조건부 시나리오)로 둔다. KDI 2012 예타 목차에 관광 항목이 없으므로 "공식 평가가 다루지 않은 측면"이라는 차별점은 말할 수 있다.

## 2. 국내·대전
- 국내 트램 관광 효과 **실증 0건**(트램 미개통). 전주 한옥마을 관광트램 기본구상(2021): 연 64만~93만 명, 사업비 639억, 생산유발 259억 — 3.3km 관광지 내 순환선의 사전 추정이라 대전 2호선과 비교 불가(기사·미검증).
- 대전 2호선 공식 문서(KDI 2012 예타 목차, 2024 총사업비 보도)에 **관광 항목 없음**.
- 대전 관광 수치 주의: 0시 축제 110만(2023)→200만(2024, 외지인 44.3%)→216만(2025)은 **집계 방식이 매년 달라** 시계열 비교 불가. 데이터랩 외지인 방문자 6,947만(2020)→8,463만(2024)은 '목적 불문 외지인 연인원'이며 기사 간 단위 불일치(8,463만 vs 846만). 성심당 1,000만 명은 자체 추산. **모두 트램 효과의 기준선·결과로 쓰지 않음.**

## 4. 적용 방안 (요약, 상세는 보고서)
1. 상권 20개를 **관광자원형**(관광지점·핵심 상점 500m 안) / **생활형**으로 층화. 관광 모듈은 관광자원형에만.
2. 보유 자료에 관광지점 입장객·데이터랩 구 단위 방문자(배경 추세)·외지인 카드 결제·숙박업소를 붙임.
3. 접근성 지수 A_j = Σ_i w_i / TT_ij 를 트램 전·후로 계산 → Δln A_j (수 분 절감이라 작게 나오는 것이 정상).
4. Δln(외지인 결제 건수) = ε × Δln A_j, ε ∈ {0, 0.5~0.7, 1.0}. 건수(도착)와 건당 금액·숙박 비중(체류)을 나눠 보고.
5. 24개월 S-커브, 개통 0~6개월 노벨티 구간 분리.
6. 개통 후 사후 검증 설계를 미리 제출: 상권×월 PPML DiD(정거장 500m), 거리 밴드, 축제·카드사 변경 더미, siphoning(비정거장 상권 현지인 매출) 점검.

## 5. 말할 수 있는 것 / 없는 것
- 가능: 관광도시 레거시 노면전차는 방문객 약 4할이 이용 · 통근형 신설 트램은 5% 미만일 수 있음 · 상인 인식과 데이터가 어긋날 수 있음(골드코스트) · 접근성 개선으로 도착은 늘어도 체류·1인당 소비는 늘지 않거나 줄 수 있음(HSR 3국).
- 불가: "트램이 대전 관광객을 X% 늘린다" · 숙박·호텔 가동률 증가 · 0시 축제·성심당 성장을 트램 근거로 · 샬럿 −66%(경전철)·이탈리아 외국인 2.279(국제 HSR)를 그대로 투입 · 전주 관광트램 수요와 비교.
