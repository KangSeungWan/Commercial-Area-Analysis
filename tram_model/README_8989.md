## 분석 결과 (2026-10-24, `analyze_8989.py`)

실행: `python tram_model/analyze_8989.py` → `outputs/8989/dong_8989_summary.csv`, `validation_8989.csv`, `tram_zone_compare.csv`, `area_dong_share.csv`, `area_sales_8989.csv`, `area_sales_summary.csv`, `dong_sales_validation.png`, `area_sales_yoy.png`

- 범위: 82개 동 전부 매출 있음. 79개 소분류 합계 ≈ 월 7,000억 원(2026-07), 사이트 메인의 전체 카드매출 1조 2,067억 원보다 작음 → 8989 업종 체계에 없는 업종(운수·공공 등)은 빠진 값. 상위 업종 = 종합소매(대형마트) 1,970억, 음식점 1,096억, 병원 909억, 연료소매 834억.
- 점포당 매출(8989 생존 사업자 수 기준) 중앙동 37만 원/월로 최하(대전 중앙값 355만) → 전통시장 현금·간이과세 거래가 카드에 안 잡힘. **중앙동·대흥동·오정동·온천1동 등 시장 많은 동은 카드매출 과소** → 상권 A03 소제동·A04 대전역·중앙시장 배분값도 과소.
- 외부 검증(행정동 82, 스피어만): 매출 증감 2025→2026(1~8월 동월)은 **주민 인구 증감과 가장 강함(ρ +0.55)** → 용문동 +39%, 은행선화동 +21%는 재개발 입주 효과. 원도심(동구·중구)일수록 낮음(ρ −0.32), 정거장에서 멀수록 높음(ρ +0.27). 실태조사 '매출 감소' 응답률은 유동인구 증감과 음(ρ −0.32). 음식점 비중 높은 동은 폐업률 높고 점포당 매출 낮음(ρ −0.45).
- 유동인구는 82개 동 **전부 전년 대비 감소**(중앙값 −9%, 2024→2026 −12~−16%) → 실제 변화라기보다 집계 방식·통신사 변경 가능성. 수준 비교만 쓰고 추세로 쓰지 말 것.
- 트램 영향권(500m 안 점포 ≥50%, 21개 동) 매출 증감 평균 −0.5% vs 밖 +2.2% → 원도심 효과와 섞여 있음. 트램 효과가 아니라 '현재 기준선'.
- 상권 20개 배분 매출: 위험 점수 vs 매출 증감 ρ −0.41(p 0.05) → 우리 진단 방향과 일치. 진단별 평균: 성장 지속 +7.6%, 쇠퇴 우려 +5.3%(은행선화 입주·신탄진 포함), 정체·안정 +0.8%, **트램 반등 기회 −1.3%**(서대전네거리 −6.5%, 복합터미널 −3.2%) → "지금 가장 약한 곳이 트램 대상"이라는 발표 논리에 맞음.
- 배분 가중치 주의: A03 소제동(중앙동의 5%), A12 도룡동(신성동의 10%), A13 궁동–어은동(온천2동 28%)은 동 전체 매출을 소수 비율로 나눈 값이라 **상권 특성 반영 안 됨**. 가중치 ≥0.5인 상권만 수치 인용 권장(`area_sales_summary.csv` 의 `main_dong_weight`).

## 월간 상권동향 PDF (2026-01~07, `parse_8989_reports.py`, 2026-10-24)

- 입력: `data/raw/8989/reports/N월.pdf` (사이트 '월별 동향 분석' 보고서). 6월 PDF는 한글 글꼴이 빠져 이름을 5월 순서로 붙였고, 7월 동구 상점가 2행(대전상가·역전시장상점가)은 글자 간격 문제로 수기 입력.
- 출력 `outputs/8989/`: `report_city_monthly.csv`(대전 전체 월별 지표, PDF 값 직접 입력), `report_gu_mom.csv`(5개 구 전월 대비), `report_alley_monthly.csv`(골목상권 143~144 × 월 × 신용카드/온통대전/유동인구 전월 대비 %), `report_alley_cumulative.csv`(2025-12→2026-07 누적 변화율, 135개), `report_alley_area_match.csv`(20개 상권 ↔ 골목상권 이름 키워드 대응; A01 복합터미널·A03 소제동은 해당 없음)
- 쓰임: API에 없는 **골목상권 단위** 카드매출 흐름. 전월 대비 %만 있어 수준 비교 불가, 월별 변동 큼(표준편차 10~30%p). 누적값에는 12월→7월 계절성이 들어 있으므로 상권 간 상대 비교만.
- 결과 요약(누적 카드매출, 대응 상권 평균): 도룡동 +19%, 궁동–어은동 +5.5%, 신탄진 +0.2%, 은행·선화 −1.7% / 유성온천 −16%, 서대전네거리 −13%(오류시장 −50%), 송촌–법동–중리 −10%, 대전역·중앙시장 −9.5% → 트램 반등 기회 상권들이 골목상권 기준으로도 약세. 유동인구 누적은 원도심(은행·선화 +17%, 서대전 +21%)이 신도심(둔산·노은 −5~−15%)보다 높음 → API 유동인구와 방향이 달라 집계 기준 확인 필요.
- 교차검증: 대전 전체 카드매출 1조 2,067억(7월) vs API 79업종 합계 7,037억 → 58%. 온통대전 7월 −79%는 온통대전 2.0 전환(9월 시행 예고) 영향 → `selng02`는 매출 지표로 부적합 확정.
